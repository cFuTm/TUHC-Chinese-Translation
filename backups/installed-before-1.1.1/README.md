# UHC 简体中文与英文切换 mod

本 mod 为 UHC 2.8.1 添加地址栏语言按钮。点击按钮或按 `Alt+Shift+L`，即可切换 Homestuck 主线的正文、页面标题和下一页链接文字。首次启用时显示简体中文，后续记住语言选择。

## 安装

1. 退出 UHC。
2. 将整个 `uhc-zh-en` 文件夹复制到 Asset Pack 的 `mods` 文件夹。
3. 确认文件路径为 `Asset_Pack/mods/uhc-zh-en/mod.js`。`translations.json`、`style.css` 和 `formatted.css` 应与 `mod.js` 同级。
4. 启动 UHC。
5. 在 UHC 地址栏输入 `/settings/mod`，打开 Mod Settings。
6. 将“简体中文 / English 一键切换”从左侧列表拖到右侧 **Active** 列表。
7. 点击 **Reload Application**。

本工作区的目标文件路径是：

```text
F:\Et Cetera\Homestuck\unofficial-homestuck-collection\Asset_Pack\mods\uhc-zh-en\mod.js
```

也可以将发布 ZIP 解压到 `Asset_Pack/mods`。ZIP 已包含 `uhc-zh-en` 这一层目录。不应再增加一层同名目录。

只需安装这个文件夹。使用 mod 不需要 Python、Node.js 或联网，也不需要复制提取工具及其依赖。

## 阅读与切换

1. 打开 Homestuck 主线页面，例如在 UHC 地址栏输入 `/mspa/001904`。
2. 点击地址栏右侧的 **中文** 按钮，切换到英文。按钮随之显示 **EN**。
3. 再次点击 **EN**，切回简体中文。

快捷键是 `Alt+Shift+L`。输入框、可编辑区域和中文输入法组合输入期间，快捷键不会触发切换。Flash 或嵌入游戏获得键盘焦点时，可使用地址栏按钮。

切换时保持当前页面和聊天记录的展开状态。mod 不更换媒体地址，也不重建媒体组件。mod 尝试保留阅读区域的滚动位置；中英文高度不同时，位置可能变化。

语言选择作用于当前 UHC 窗口内的阅读组件，翻页后继续使用所选语言。重载或重新打开应用后，mod 会恢复已保存的语言。

## 缺译页面

如果没有中文正文，mod 显示原文，并将按钮标为 **中文·原文**。页面标题可以来自中文译文，正文同时使用英文回退。

本版本包含 8,123 条可对应本地 UHC 的页面资料，其中有 5,699 页非空中文正文。纯图片页等页面的正文为空，这种情况不会标记为缺译。47 个主线页号需要保留原文回退，列表见 `build-report.json` 中的 `bodyFallbackPageIds`。

## 内容范围

切换范围是 Homestuck 主线的普通页面文本。以下内容继续使用原内容：

- 图片内的文字、GIF 和视频内的文字。
- Flash、Openbound 等动画或游戏内部的文字。
- 尾声、Vast Error、Homestuck² 和其他附加作品。
- UHC 的设置界面、标签页名称、搜索索引、阅读目录和书签名称。

普通聊天记录的显示与隐藏按钮会随语言切换。特殊密码提示保留原文，避免改变提示含义。

译文优先使用用户提供的 `blog.xml` 带格式正文，另用《繁中翻译.txt》和 `homestuckjz.GitHub.io` 站点副本补充。整合数据使用 OpenCC `t2s` 转为简体，尚未人工校对。整合者不是原译文作者；译者署名以原始资料为准。

1.1.0 的 4,531 页正文直接保留 XML 中的颜色、字号、字体、粗体、下划线和段落格式。118 页含特殊字号，56 页需要独立的局部 CSS。样式只作用于对应页的中文正文，切回英文后不再生效。博客的脚本、媒体播放器和页面导航没有导入。

XML 没有可用正文的 9 页继续使用原有纯文本补充，包括两页互动攻略和七页导航文字。后期网站的 1,159 页补充正文继续保留。已安装旧版中 17 页的“数据结构”“哈希”等术语修订也已保留。

UHC 的高对比度设置会重新调整部分文字颜色。若需要查看 XML 的原始颜色，请关闭高对比度设置。正文中的定时文字动画会在重新切换到中文时重新开始。复杂的图文交错布局仍以 UHC 的媒体布局为准。

## 故障排查

| 现象 | 检查与解决方法 |
| --- | --- |
| Mod Settings 没有显示本 mod | 检查 `mod.js` 路径，确认没有多套一层文件夹，然后退出并重新启动 UHC |
| 显示版本不兼容 | 使用 UHC 2.8.1 或更高版本；本版本仅完成了对本地 2.8.1 组件的验证 |
| 启用后没有按钮 | 确认 mod 位于 Active 列表，然后点击 Reload Application |
| 某页正文仍是英文 | 查看按钮是否为“中文·原文”；图片、动画和游戏内的文字不属于普通正文 |
| 与其他文本或界面 mod 冲突 | 将本 mod 拖到 Active 列表上方，然后重载应用；仍有冲突时，逐个停用同时改写页面组件的 mod |
| 更新文件后仍显示旧效果 | 退出 UHC，替换整个 `uhc-zh-en` 文件夹，再启动 UHC |

## 停用与移除

1. 打开 `/settings/mod`。
2. 将本 mod 从 Active 列表拖回左侧列表。
3. 点击 Reload Application。
4. 如需移除文件，退出 UHC 后删除 `Asset_Pack/mods/uhc-zh-en` 文件夹。

mod 没有改写 Asset Pack 的原始正文或媒体文件。停用后，UHC 使用原来的页面文本。

## 验证与版本

版本为 `1.1.0`，最低应用版本为 `2.8.1`。

集成测试读取本地 `app.asar`，运行其中的真实 mod 混入逻辑及 Page、PageText、PageNav 组件。测试环境使用与本地 UHC 相同的 Vue 2.7.16，并通过 DOM 环境模拟页面。

已验证按钮切换、翻页后的语言、正文回退、页标题和链接。测试也检查了聊天展开状态与颜色、媒体节点保留、原文数据不变和语言持久化。网站页号、Ryanquest 排除和快捷键清理均已通过检查。尚未在桌面应用中逐页验收，也没有验证游戏内部文字切换。
